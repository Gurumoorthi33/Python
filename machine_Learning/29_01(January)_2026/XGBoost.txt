What is gradient Boosting ?
          
          1. Gradient Boosting is a machine learning algorithms that sequentialy ensembles weak predictive models into a stronger predictive models.
          2. Good for both supervised regression and classification problems.
          3. Most weak ensembles models to the ensembles are decision trees.
          advantages: performant and easy to use.
          disadvantages: overfit and a lot of computing power.

XGBoost: tree based gradient boosting key improvements.
         * regularized.
            eg. theobjective function of the XGBosst has a regularization term added to the loss function.
         * More Scalable.
            eg. Memory Optimization, Cache Optimization, Distributed Computing.

XGBOOST is a faster framework that can build better models.
